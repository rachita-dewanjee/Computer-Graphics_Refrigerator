# 3D Refrigerator in Three.js

Computer graphics project: a textured 3D refrigerator built step by step with Three.js (WebGL).

## Demos
| File | What it shows |
|---|---|
| `cube.html` | Scene, camera, renderer and a basic cube mesh |
| `cubeRotation.html` | Animating the cube's rotation |
| `lighting.html` | Ambient, point and directional lights with Phong materials |
| `mouseClick.html` | Changing the object with mouse clicks |
| `shaderMaterial.html` | A custom GLSL vertex and fragment shader material |
| `texture.html` | **The textured refrigerator**: image textures on the body and inside, a textured floor, and keyboard and mouse controls |

## Tech
JavaScript, Three.js, WebGL, HTML.

## Run
Open the folder with a local web server (for example the VS Code **Live Server** extension, or
`python -m http.server`) and open any `.html` file. Textures load only when served, not when the file
is opened directly.
